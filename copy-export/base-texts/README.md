# base-texts

Copies of the files where Atlas's text is written down, at their repo paths under each category. `manifest.csv` lists them all.

| Folder | Files | What |
|---|---|---|
| `mcp/` | 314 | MCP server: tool names, titles, descriptions, parameter descriptions, instructions, prompts, replies, and the atlas-mcp bridge |
| `prompts/` | 54 | Prompt texts sent to the assistant (Claude Code, API-key assistant) and briefs/directions |
| `checks/` | 98 | Built-in check templates (store text guidelines, screenshot/artwork/capture checks, preflight, problems) |
| `autopilot-steps/` | 52 | Autopilot steps, stages, guided-run turns and progress texts |
| `analytics-findings/` | 8 | Analytics findings templates (What to Try) and their rules |
| `notifications/` | 13 | macOS notification titles/bodies/actions and the notifiers that post them |
| `help/` | 38 | Help articles (Markdown) and the Help window's own texts |
| `onboarding-tour/` | 38 | Welcome flow, first-run tour tips, Connect help steps and first sync |
| `menus/` | 14 | App menu commands, menu bar extra and its menu |
| `apple-words/` | 4 | Apple's own App Store words copied per language for previews (not Atlas copy) |
| `string-catalogs/` | 2 | No .xcstrings/.strings exist in the repo. Generated draft `Localizable.extracted.xcstrings` (9,463 keys) and `compiler-extracted-strings.json` (every occurrence with file:line) |
| `info-plist/` | 3 | Built Info.plist (no usage descriptions), Info.plist build settings, atlas-mcp entitlements |
| `mcp/mcp-tools.json`, `mcp/mcp-tools.md`, `mcp/server-instructions.txt` | 3 | The 117 tools' names, titles, descriptions and parameter descriptions, plus the server instructions, extracted from source |
